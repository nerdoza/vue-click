vue-click

A v-click directive for Vue 3 with double click, hold, repeat, press and release behaviors, and once, throttle and debounce modifiers.

Documentation · npm · Source of this page

npm install vue-click

Each button is labeled with its directive and counts how many times it fired. Try them with a mouse, a finger and the keyboard.

Click

Fires when the button is pressed and released within 300ms. Unlike v-on:click, it ignores slow presses, drags and right clicks.

Double click

Fires on the second of two clicks. The second click has to start within the time: 300ms unless you set one.

Hold

Fires once the button has been held down for the time, 300ms by default. Letting go early or sliding off cancels it.

Repeat

Fires on press, then again every 100ms (or the time you set) while held, starting after 300ms. Made for steppers and scroll arrows.

Press and release

Fire on the way down and on the way up, without waiting for a whole click.

Once

Fires the first time, then removes itself and marks the button with data-vc-state-deactivated. Reset to try again.

Throttle

Fires on the first click, then ignores clicks until none have come for the time. Click quickly to see the extra clicks dropped.

Debounce

Waits until the clicks have stopped for the time, then fires once.

Arguments

The directive's argument reaches the handler as a string. For any other value, use an arrow function.

show received: {{ received }}

Combining

v-click with v-click.hold tells a tap from a long press: only one of them fires. Most other pairs both fire, such as a click and a double click.

Nested elements

A press on a v-click inside another fires both, unless the inner one has stop.

Disabled

Clicks are ignored while the button is disabled.

Styling

Pressed elements get data-vc-state-active, which is more reliable than :active. Each behavior also adds an attribute, such as data-vc-bind-hold. This page uses:

button[data-vc-state-active] {
  box-shadow: inset 0 0 8px #0006;
}

button[data-vc-state-deactivated] {
  opacity: 0.5;
}

button[data-vc-bind-hold] {
  border-style: dashed;
}
